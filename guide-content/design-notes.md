# PDF Design Notes (for Canva)

Notes on visual design for when we build the actual PDF. These can't be done in the markdown drafts.

## Tier Colour Coding

Assign each tier a consistent colour throughout the guide. Everywhere a tier appears (tables, shopping lists, callout boxes), use its colour so readers can instantly find "their column."

- **Weekender** — e.g. green / light teal
- **Tourer** — e.g. blue / mid-blue
- **Full-timer** — e.g. orange / amber

Use these as column headers, table row highlights, and badge colours on the shopping lists. The goal: a reader identifies their tier once and then just follows their colour through the whole guide.

Applies to:
- Section 3: "Your Complete System at a Glance" table
- Section 4: Shopping lists (one per tier)
- Section 5: Sizing worked examples
- Any other tier-specific content

## General Design Direction

- Clean, printable on A4
- Not flashy — trustworthy and clear
- Generous whitespace, large text (audience is 55-75)
- "The short version" callout boxes should be visually prominent — bordered, maybe lightly shaded — so skimmers can find them instantly
