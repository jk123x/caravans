## Quick Reference: Common Appliance Wattages

| Appliance | Typical Wattage |
|-----------|----------------|
| Compressor fridge (3-way, 12V) | 50-70W |
| LED light strip (per metre) | 5-15W |
| LED ceiling lights (all) | 20-40W |
| 12V TV (19-24 inch) | 30-60W |
| USB phone charger | 10-20W |
| Laptop charger | 45-65W |
| Water pump (Shurflo etc) | 50-70W |
| Diesel heater fan | 20-40W |
| 12V fan | 15-30W |
| CPAP machine (12V) | 30-60W |
| Microwave (via inverter) | 800-1200W |
| Hair dryer (via inverter) | 1200-2000W |
| Coffee machine (via inverter) | 800-1500W |
| Toaster (via inverter) | 800-1200W |

**Note:** Appliances running through the inverter use roughly 10-15% more from the battery due to conversion losses. Factor this in by using the higher end of the wattage range.
